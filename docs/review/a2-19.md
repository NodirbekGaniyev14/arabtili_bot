## Grammatika
**Nuqta:** أَوْزَانُ المَصْدَر
Masdar — fe'lning «ish nomi» (o'zbekcha «-sh, -moq»). I bobning masdari turlicha (yodlanadi: عِلْم, كِتَابَة, ذَهَاب). Lekin II–X boblarning masdari ANIQ vaznda: II → تَفْعِيل (تَعْلِيم), III → مُفَاعَلَة (مُسَاعَدَة), IV → إِفْعَال (إِعْلَام), V → تَفَعُّل (تَعَلُّم), VI → تَفَاعُل (تَعَاوُن), VII → اِنْفِعَال (اِنْكِسَار), VIII → اِفْتِعَال (اِجْتِمَاع), X → اِسْتِفْعَال (اِسْتِغْفَار).
- II: تَفْعِيل — تَعْلِيم (ta'lim)
- IV: إِفْعَال — إِعْلَام (xabar berish)
- V: تَفَعُّل — تَعَلُّم (o'rganish)
- X: اِسْتِفْعَال — اِسْتِعْلَام (so'rov)
