## Grammatika
**Nuqta:** الأَجْوَف — تَحَوُّلُ الوَسَط
Ajvaf fe'l — o'rta o'zak harfi و yoki ي. O'TGAN zamonда o'rta illat ALIF ga aylanadi: ق و ل → قَالَ, ب ي ع → بَاعَ. HOZIRGI zamonда asl harf qaytadi: يَقُولُ (و), يَبِيعُ (ي), يَنَامُ (ا). Qisqargan shakllarda (masalan لَمْ bilan) o'rta harf tushib qoladi: لَمْ يَقُلْ (aytmadi).
- قَالَ ← يَقُولُ — dedi → aytadi (ق و ل)
- بَاعَ ← يَبِيعُ — sotdi → sotadi (ب ي ع)
- كَانَ ← يَكُونُ — edi → bo'ladi (ك و ن)
- نَامَ ← يَنَامُ — uxladi → uxlaydi (ن و م)
