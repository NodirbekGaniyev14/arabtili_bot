# Tekshiruv varag'i — a0-19: Ulanish mashqi: ikki harf
**Can-do:** Ikkita harfni to'g'ri qo'shib bitta birikma qilib yozaman va ularni ajrata olaman.
**Harakat darajasi:** none

## Lug'at (harakat va tarjima to'g'riligini tekshiring)
| Arabcha | Translit | O'zbekcha | O'zak | Vazn | ✓/✗ |
|---|---|---|---|---|---|
| بت | b-t | bo va to tutashgan birikma (hali so'z emas) |  |  | |
| نم | n-m | nun va mim tutashgan birikma |  |  | |
| لك | l-k | lom va kof tutashgan birikma |  |  | |
| اب | a-b | alif va bo — alifdan keyin uzilgan |  |  | |

## Grammatika
**Nuqta:** وَصْلُ الحُرُوف
Arab yozuvida harflar tutashadi. Har harfning uch shakli bor: BOSHIDA (بـ), O'RTADA (ـبـ), OXIRIDA (ـب). Ikki harf qo'shilganda birinchisi «boshi» shaklida, ikkinchisi «oxiri» shaklida keladi: بـ + ـت = بت. LEKIN 6 ta harf (ا د ذ ر ز و) keyingi harfga ULANMAYDI — ulardan keyin uzilish bo'ladi: بـ + ا = با, lekin ا + ب = اب (a dan keyin uzilish). Hali harakat qo'ymaymiz — bu faqat SHAKL mashqi, o'qish keyingi darslarda.
- بـ + ـت = بت — bo + to tutashdi
- نـ + ـم = نم — nun + mim tutashdi
- ا + ب = اب — alifdan keyin uzilish
- د + ت = دت — doldan keyin uzilish

## Mikro-test javoblari
1. [mcq] بت birikmasida nechta harf bor? → **2**
2. [mcq] Qaysi harfdan keyin ulanish UZILADI? → **ا (alif)**
3. [mcq] بـ shakli so'zning qayerida keladi? → **boshida**
4. [mcq] نـ + ـم nima beradi? → **نم**
5. [mcq] Hozirgi darsda nega harakat (unli) yo'q? → **Faqat ulanish shaklini o'rganamiz**
6. [mcq] لـ + ـك birikmasi qaysi? → **لك**
