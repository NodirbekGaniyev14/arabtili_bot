## Grammatika
**Nuqta:** اِنْفَعَلَ — المُطَاوَعَة
VII bob vazni: اِنْفَعَلَ (o'zak boshiga اِنْـ). Asosiy ma'no: NATIJA / passiv-qaytim — «o'zi ... bo'ldi»: كَسَرَ (sindirdi) → اِنْكَسَرَ (sindi), فَتَحَ (ochdi) → اِنْفَتَحَ (ochildi). Bu fe'llar o'timsiz (ob'ekt olmaydi). Masdari اِنْفِعَال: اِنْكِسَار. Hozirgi zamoni: يَنْفَعِلُ (يَنْكَسِرُ). Boshidagi hamza — «vasl» (ulanishда tushadi).
- كَسَرَ ← اِنْكَسَرَ — sindirdi → sindi
- فَتَحَ ← اِنْفَتَحَ — ochdi → ochildi
- اِنْتَهَى — tugadi, tugallandi
- مَصْدَر: اِنْكِسَار — masdar: sinish
