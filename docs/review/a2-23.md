## Grammatika
**Nuqta:** المِثَال — سُقُوطُ الوَاو
Mithal fe'l — boshi و (ba'zan ي). ASOSIY qoida: o'tgan zamonда و SAQLANADI (وَصَلَ), lekin hozirgi zamonда و TUSHADI: وَصَلَ → يَصِلُ (yasilu, و yo'q!), وَجَدَ → يَجِدُ, وَقَفَ → يَقِفُ. Buyruqда ham و tushadi: صِلْ! (yet!). Bu faqat mithal fe'llarга xos.
- وَصَلَ ← يَصِلُ — yetib keldi → keladi (و tushdi)
- وَجَدَ ← يَجِدُ — topdi → topadi
- وَعَدَ ← يَعِدُ — va'da berdi → beradi
- وَقَفَ ← يَقِفُ — to'xtadi → to'xtaydi
