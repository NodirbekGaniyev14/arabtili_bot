## Grammatika
**Nuqta:** الإِعْرَابُ: رَفْعٌ · نَصْبٌ · جَرٌّ · جَزْمٌ
XULOSA JADVALI — kim qaysi holatda? RAF' (damma): ega (فاعل), mubtada, xabar, majhul egasi. NASB (fatha): ob'ekt (مفعول به), kana xabari, inna egasi, HOL, TAMYIZ, maf'ul mutlaq, maf'ul li-ajlih, mansub muzori' (أنْ dan keyin), istisno (tasdiqda). JARR (kasra): predlogdan keyin, idofada ikkinchi so'z. JAZM (sukun): لم/لا الناهية/إنْ dan keyingi muzori'. TARTIB: (1) fe'lmi-otmi? (2) vazifasi nima? (3) holati mos keladimi?
- كتبَ الطالبُ الدرسَ — fe'l + ega (raf') + ob'ekt (nasb)
- إنَّ العلمَ نورٌ — inna + ega (nasb!) + xabar (raf')
- ذهبتُ إلى المسجدِ — predlog + jarr (kasra)
- لم أفهمْ فهمًا تامًّا — jazm + maf'ul mutlaq (nasb)

## Mikro-test javoblari
1. [mcq] «كتبَ الطالبُ الدرسَ» — الطالبُ nima va nega raf'da? → **fo'il (ega) — fo'il doim raf'da**
2. [mcq] «إنَّ العلمَ نورٌ» — العلمَ nega nasbda? → **inna egasi nasbda bo'ladi**
3. [mcq] «ذهبتُ إلى المسجدِ» — المسجدِ nega kasrada? → **predlogdan keyin jarr**
4. [mcq] «جاء الولدُ ضاحكًا» — ضاحكًا vazifasi? → **hol (nasb)**
5. [mcq] «لم أفهمْ» — أفهمْ nega sukunda? → **لم jazm qiladi**
6. [fill_blank] To'ldiring: «Damma — ____ belgisi» (arabcha atama) → **الرَّفْعِ**
7. [match_root] «إِعْرَاب، أَعْرَبَ» qaysi o'zakdan? → **ع ر ب**
