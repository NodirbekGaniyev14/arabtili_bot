## Grammatika
**Nuqta:** المَبْنِيُّ لِلْمَجْهُول
Majhul (passiv) — bajaruvchi (fo'il) aytilmaydi, faqat ish tushgan narsa (نَائِب الفَاعِل) qoladi va u RAF'да bo'ladi. O'TGAN zamon majhuli: 1-harf DAMMA, o'rta KASRA: كَتَبَ → كُتِبَ (yozildi), فَتَحَ → فُتِحَ (ochildi). HOZIRGI zamon: يُـ prefiks damma, o'rta fatha: يَكْتُبُ → يُكْتَبُ (yoziladi). Ma'lum (aktiv) — كَتَبَ الوَلَدُ الرِّسَالَةَ; majhul — كُتِبَتِ الرِّسَالَةُ.
- كَتَبَ ← كُتِبَ — yozdi → yozildi
- فَتَحَ ← فُتِحَ — ochdi → ochildi
- يَكْتُبُ ← يُكْتَبُ — yozadi → yoziladi
- خُلِقَ الإِنْسَانُ — Inson yaratildi
