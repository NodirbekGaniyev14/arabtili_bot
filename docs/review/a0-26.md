## Grammatika
**Nuqta:** السُّكُون ( ْ )
Sukun — harf ustiga qo'yiladigan kichik doiracha ( ْ ). U harfda hech qanday unli (fatha, kasra, damma) yo'qligini bildiradi. Ya'ni harf 'a', 'i', 'u' bilan emas, balki yolg'iz undosh sifatida o'qiladi. Masalan مَكْتَب so'zida: مَ = 'ma', كْ = 'k' (unlisiz, sukun bilan), تَ = 'ta', ب = 'b'. Natija: mak-tab. Sukun ikki undoshni birlashtirib, yopiq bo'g'in hosil qiladi.
- مَ — ma (fatha bilan)
- كْ — k (sukun bilan, unli yo'q)
- دَرْس — dars — رْ = 'r' unlisiz
- عِلْم — ilm — لْ = 'l' unlisiz
- بِنْت — bint (qiz) — نْ = 'n' unlisiz
