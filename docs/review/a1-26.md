## Grammatika
**Nuqta:** جَمْعُ المُذَكَّر / المُؤَنَّث السَّالِم
«Sog'lom ko'plik» (o'zak buzilmasdan qo'shimcha bilan) ikki xil: (1) ERKAK aql egalari uchun ـُونَ (raf') / ـِينَ (nasb/jarr): مُسْلِم → مُسْلِمُونَ. (2) AYOL uchun ـَاتٌ (ة tushadi): مُسْلِمَة → مُسْلِمَات. Diqqat: ـُونَ faqat aqlli erkaklar uchun; narsalar boshqacha ko'plik oladi (keyingi dars).
- مُعَلِّم ← مُعَلِّمُونَ — o'qituvchi → o'qituvchilar
- مُعَلِّمُونَ ← مُعَلِّمِينَ — raf' → nasb/jarr
- مُعَلِّمَة ← مُعَلِّمَات — o'qituvchi (ayol) → ular
- مُسْلِمُونَ وَمُسْلِمَاتٌ — musulmon erkaklar va ayollar
