## Grammatika
**Nuqta:** اِفْتَعَلَ — المُطَاوَعَة
VIII bob vazni: اِفْتَعَلَ (o'zak boshiga اِ, 1-harfdan KEYIN تَـ qo'shiladi). Asosiy ma'no: qaytim / o'z manfaatiga bajarish: جَمَعَ (to'pladi) → اِجْتَمَعَ (to'plandi), سَمِعَ (eshitdi) → اِسْتَمَعَ (diqqat bilan tingladi). Masdari اِفْتِعَال: اِجْتِمَاع (yig'ilish), اِحْتِرَام (hurmat). Hozirgi zamoni: يَفْتَعِلُ (يَجْتَمِعُ).
- جَمَعَ ← اِجْتَمَعَ — to'pladi → to'plandi
- سَمِعَ ← اِسْتَمَعَ — eshitdi → tingladi
- اِحْتَرَمَ — hurmat qildi
- مَصْدَر: اِجْتِمَاع — masdar: yig'ilish
