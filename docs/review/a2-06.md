## Grammatika
**Nuqta:** مِنَ المَاضِي إِلَى المُضَارِعِ
Almashtirish 3 qadamda bo'ladi. (1) Moziy fe'lning OXIRGI qo'shimchasini olib tashlang va kim haqida gap ketayotganini aniqlang: كَتَبْنَا → «biz». (2) Shu shaxsga mos MUZORI' prefiksini qo'ying: biz → نـ. (3) Muzori' qo'shimchasini qo'shing: نَكْتُبُ. Kelasi zamon uchun esa alohida fe'l yasamaysiz — muzori'ning OLDIGA سَـ (yaqin kelajak) yoki سَوْفَ (uzoq kelajak) qo'shasiz: سَيَكْتُبُ، سَوْفَ نُسَافِرُ. Zamon ishoralari yordam beradi: أَمْسِ (kecha) → moziy, الآنَ / اليَوْمَ (hozir) → muzori', غَدًا (ertaga) → سَـ + muzori'.
- كَتَبَ ← يَكْتُبُ — u yozdi → u yozadi
- كَتَبَتْ ← تَكْتُبُ — u (ayol) yozdi → yozadi
- كَتَبَا ← يَكْتُبَانِ — ikkovi yozdi → yozadi
- كَتَبُوا ← يَكْتُبُونَ — ular yozdilar → yozadilar
- كَتَبْنَ ← يَكْتُبْنَ — ular (ayollar) yozdilar → yozadilar
- كَتَبْتَ ← تَكْتُبُ — sen yozding → yozasan
- كَتَبْتِ ← تَكْتُبِينَ — sen (ayol) yozding → yozasan
- كَتَبْتُ ← أَكْتُبُ — men yozdim → yozaman
- كَتَبْنَا ← نَكْتُبُ — biz yozdik → yozamiz
- سَيَكْتُبُ / سَوْفَ نُسَافِرُ — yozadi (kelasi) / safar qilamiz (kelasi)
- أَمْسِ / اليَوْمَ / غَدًا — kecha (moziy) / bugun (muzori') / ertaga (سَـ)
