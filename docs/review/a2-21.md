## Grammatika
**Nuqta:** صِيَاغَةُ فِعْلِ الأَمْر
Buyruq (أَمْر) hozirgi zamon fe'lidan yasaladi: (1) تَـ prefiksni olib tashlang: تَكْتُبُ → كْتُبُ. (2) Agar qolgan qism sukunли harfдan boshlansa, boshiga «vasl hamzasi» qo'shing: اُكْتُبْ (o'rta unli damma → اُ), اِجْلِسْ (o'rta unli kasra → اِ). (3) Oxiri sukunли (jazm): اُكْتُبْ. Ajvaf/naqisда oxir tushadi: قُلْ! (ayt!), اِمْشِ! (yur!).
- تَكْتُبُ ← اُكْتُبْ — yozasan → yoz!
- تَقْرَأُ ← اِقْرَأْ — o'qiysan → o'qi!
- تَجْلِسُ ← اِجْلِسْ — o'tirasan → o'tir!
- تَقُولُ ← قُلْ — aytasan → ayt! (ajvaf)
