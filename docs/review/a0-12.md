# Tekshiruv varag'i — a0-12: ف va ق
**Can-do:** fo va qof harflarini shakli, nuqtasi va tovushi bo'yicha ajrataman.
**Harakat darajasi:** full

## Lug'at (harakat va tarjima to'g'riligini tekshiring)
| Arabcha | Translit | O'zbekcha | O'zak | Vazn | ✓/✗ |
|---|---|---|---|---|---|
| ف | fā (f) | fo — halqa + tayoq, TEPADA 1 nuqta — «f» |  |  | |
| ق | qāf (q) | qof — halqa + kosacha, TEPADA 2 nuqta — o'zbekcha «q» |  |  | |

## Grammatika
**Nuqta:** ف ق
ف (fo) — halqa + gorizontal tayoq, TEPADA 1 nuqta, «f». ق (qof) — halqa + pastga tushgan kosacha, TEPADA 2 nuqta, «q» — o'zbekcha «qalam» dagi q, bo'g'iz orqasidan chiqadi. Farqi: ف ning dumi chiziq ustida, ق niki chiziq ostiga tushadi. Ikkalasi ulanadi: فـ ـفـ ـف · قـ ـقـ ـق.
- ف — fo — halqa + tayoq, TEPADA 1 nuqta — «f»
- ق — qof — halqa + kosacha, TEPADA 2 nuqta — o'zbekcha «q»
