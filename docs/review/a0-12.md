## Grammatika
**Nuqta:** الشَّدَّة
Shadda (ّ) — harf ustidagi kichik belgi. U harfni IKKI marta o'qishni bildiradi: birinchisi sukunli (harakatsiz), ikkinchisi harakatli. Masalan مُدَرِّس so'zida ر harfi ustida shadda bor — demak u «r-r» bo'lib o'qiladi: mu-dar-ris. Shadda o'zi bilan birga harakat oladi: fatha va damma shadda USTIDA, kasra esa odatda shadda OSTIDA yoziladi.
- ـّ — shadda belgisi — harfni ikki marta o'qi
- ـَّ — shadda + fatha (masalan: bb + a)
- ـُّ — shadda + damma (masalan: bb + u)
- ـِّ — shadda + kasra (masalan: rr + i)
- جَدّ — jadd (bobo) — d harfi ikki marta
- مُدَرِّس — mudarris (o'qituvchi) — r harfi ikki marta

## Mikro-test javoblari
1. [mcq] Shadda (ّ) belgisi nimani bildiradi? → **Harfni ikki marta o'qishni**
2. [mcq] Qaysi so'zda harf ikki marta o'qiladi? → **مُدَرِّس**
3. [translate_ar_uz] Tarjima qiling: جَدّ → **bobo**
4. [translate_uz_ar] Tarjima qiling: shakar → **سُكَّر**
5. [harakat] «mudarris» so'ziga to'g'ri harakat va shaddani qo'ying (r ustiga shadda + kasra). → **مُدَرِّس**
6. [dictation] Eshitilgan so'zni arabcha yozing → **حَجّ**
7. [match_root] «مُدَرِّس» so'zining o'zagini toping → **د ر س**
