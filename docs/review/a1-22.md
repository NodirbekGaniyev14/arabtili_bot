## Grammatika
**Nuqta:** لا + الفِعْل المُضَارِع
Hozirgi zamonni inkor qilish uchun fe'l OLDIGA لا qo'yiladi, fe'l shakli o'zgarmaydi: أَعْرِفُ (bilaman) → لا أَعْرِفُ (bilmayman); يَذْهَبُ (boradi) → لا يَذْهَبُ (bormaydi). ESLATMA: o'tgan zamon inkori مَا bilan (مَا ذَهَبَ), hozirgi zamon inkori لا bilan (لا يَذْهَبُ).
- أَعْرِفُ ← لا أَعْرِفُ — bilaman → bilmayman
- يَذْهَبُ ← لا يَذْهَبُ — boradi → bormaydi
- لا أَقْدِرُ — Qila olmayman
- لا نَفْهَمُ — Tushunmaymiz
