## Grammatika
**Nuqta:** اسْمُ الفَاعِل وَالمَفْعُول
ISM FO'IL — harakatni bajaruvchi. I bob: فَاعِل (كَاتِب — yozuvchi). II–X boblarда: مُـ prefiks + oxirdan avvalgi harf KASRA (مُعَلِّم, مُسَاعِد, مُسْتَخْدِم). ISM MAF'UL — harakat tushgan narsa. I bob: مَفْعُول (مَكْتُوب — yozilgan). II–X: مُـ prefiks + oxirdan avvalgi harf FATHA (مُعَلَّم, مُسْتَخْدَم). Farqi — oxirgi harakat: fo'il kasra (ـِ), maf'ul fatha (ـَ).
- كَاتِب / مَكْتُوب — yozuvchi / yozilgan (I)
- مُعَلِّم / مُعَلَّم — o'rgatuvchi / o'rgatilgan (II)
- مُسْتَخْدِم / مُسْتَخْدَم — foydalanuvchi / ishlatilgan (X)
- عَالِم / مَعْلُوم — olim / ma'lum (I)
