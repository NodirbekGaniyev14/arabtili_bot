# Tekshiruv varag'i — a0-03: ت va ث
**Can-do:** to va so (tishlararo) harflarini shakli, nuqtasi va tovushi bo'yicha ajrataman.
**Harakat darajasi:** full

## Lug'at (harakat va tarjima to'g'riligini tekshiring)
| Arabcha | Translit | O'zbekcha | O'zak | Vazn | ✓/✗ |
|---|---|---|---|---|---|
| ت | tā (t) | to — kosacha, TEPADA 2 nuqta — «t» |  |  | |
| ث | thā (th) | so (tishlararo) — kosacha, TEPADA 3 nuqta — tishlararo «s» (inglizcha think) |  |  | |

## Grammatika
**Nuqta:** ت ث
ت (to) — kosacha, TEPADA 2 nuqta, oddiy «t» tovushi. ث (so) — kosacha, TEPADA 3 nuqta, TISHLARARO «s»: til uchi yuqori va pastki tish orasiga chiqadi (inglizcha «think» dagi kabi). Bu tovush o'zbekchada yo'q — mashq qilish kerak. Ikkalasi ham ulanadi: تـ ـتـ ـت · ثـ ـثـ ـث.
- ت — to — kosacha, TEPADA 2 nuqta — «t»
- ث — so (tishlararo) — kosacha, TEPADA 3 nuqta — tishlararo «s» (inglizcha think)
