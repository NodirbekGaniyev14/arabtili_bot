## Grammatika
**Nuqta:** النَّاقِص — العِلَّةُ فِي الآخِر
Naqis fe'l — o'zagining OXIRGI harfi و yoki ي. O'tgan zamonда oxir ى yoki ا bo'lib yoziladi: مَشَى (م ش ي), دَعَا (د ع و). Hozirgi zamonда asl harf ko'rinadi: يَمْشِي (ي), يَدْعُو (و), يَنْسَى (ى — cho'ziq a). Qisqargan shakllarda oxirgi harf tushadi: لَمْ يَمْشِ (yurmadi).
- مَشَى ← يَمْشِي — yurdi → yuradi (م ش ي)
- دَعَا ← يَدْعُو — chaqirdi → chaqiradi (د ع و)
- بَنَى ← يَبْنِي — qurdi → quradi (ب ن ي)
- نَسِيَ ← يَنْسَى — unutdi → unutadi (ن س ي)
