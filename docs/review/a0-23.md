## Grammatika
**Nuqta:** Damma
Damma — harf USTIGA qo'yiladigan kichik vovsimon belgi (و ga o'xshaydi). U harfga «u» tovushini qo'shadi. بُ = «bu», تُ = «tu», نُ = «nu». Fatha bilan chalkashtirmang: fatha to'g'ri chiziq, damma esa halqasimon.
- بُ — «bu»
- تُ — «tu»
- نُ — «nu»
- مُ — «mu»
- لُ — «lu»

## Mikro-test javoblari
1. [mcq] Damma (ُ) qaysi tovushni qo'shadi? → **«u»**
2. [mcq] «bu» bo'g'ini qaysi? → **بُ**
3. [mcq] Damma harfning qayeriga qo'yiladi? → **ustiga**
4. [harakat] «nu» bo'g'inini tanlang: → **نُ**
5. [mcq] «mu» qaysi bo'g'in? → **مُ**
6. [mcq] Qaysi bo'g'inda DAMMA bor? → **تُ**
