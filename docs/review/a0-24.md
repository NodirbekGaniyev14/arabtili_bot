## Grammatika
**Nuqta:** الفَتْحة · الكَسْرة · الضَّمّة
Arab tilida qisqa unlilar (a, i, u) alohida harf emas, balki harf ustiga yoki ostiga qo'yiladigan mayda belgilardir. Uchtasi bor: fatha (kichik chiziq, harf USTIDA) = a; kasra (kichik chiziq, harf OSTIDA) = i; damma (kichik و shakli, harf USTIDA) = u. Bu belgilar so'z ma'nosini butunlay o'zgartiradi: كَتَبَ = «yozdi», كُتُبُ = «kitoblar».
- بَ — ba (a tovushi)
- بِ — bi (i tovushi)
- بُ — bu (u tovushi)
- كَتَبَ — kataba — yozdi
- كُتُبُ — kutub — kitoblar

## Mikro-test javoblari
1. [mcq] «كَتَبَ» so'zi nimani anglatadi? → **yozdi**
2. [mcq] Qaysi belgi «u» tovushini beradi? → **damma**
3. [mcq] Kasra belgisi harfning qayeriga qo'yiladi? → **ostiga**
4. [translate_ar_uz] شَرِبَ → **ichdi**
5. [harakat] «zahaba» (ketdi) bo'lishi uchun harakatlarni qo'ying: → **ذَهَبَ**
6. [dictation] Eshitilgan so'zni yozing: → **دَرَسَ**
7. [mcq] «كُتُبُ» nimani anglatadi? (o'zbekcha «kitob» so'zi shundan) → **kitoblar**
