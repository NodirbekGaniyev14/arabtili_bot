# Tekshiruv varag'i — a0-20: Ulanish mashqi: uch harf
**Can-do:** Uchta harfni to'g'ri tutashtirib bitta so'z shakliga keltiraman (hali harakatsiz).
**Harakat darajasi:** none

## Grammatika
**Nuqta:** وَصْلُ ثَلَاثَةِ حُرُوف
Uch harf tutashganda: birinchisi BOSHIDA (كـ), o'rtadagisi O'RTADA (ـتـ), oxirgisi OXIRIDA (ـب). Masalan كـ + ـتـ + ـب = كتب (k-t-b skeleti). Agar o'rtada ulanmaydigan harf bo'lsa, u yerda uzilish bo'ladi: مـ + ـد + ر = مدر emas, بعده uzilib — مدر kabi. Hali harakat yo'q, faqat harflar tutashuvini kuzatamiz. Bu — arab so'zining «suyagi».
- كـ ـتـ ـب = كتب — k-t-b uch harf tutashdi
- لـ ـعـ ـب = لعب — l-'-b tutashdi
- مـ ـن = من — m-n (ikki harf)
- بـ ـيـ ـت = بيت — b-y-t skeleti

## Mikro-test javoblari
1. [mcq] كتب da nechta harf bor? → **3**
2. [mcq] Uch harfdan o'rtadagisi qaysi shaklda keladi? → **o'rta (ikki tomondan tutashadi)**
3. [mcq] بـ + ـيـ + ـت nima beradi? → **بيت**
4. [mcq] Arab so'zi qaysi tomondan yoziladi? → **o'ngdan chapga**
5. [mcq] Hozir كتب ni o'qiy olamizmi? → **Yo'q — harakat (unli) yo'q**
6. [mcq] لـ + ـعـ + ـب birikmasi qaysi? → **لعب**
