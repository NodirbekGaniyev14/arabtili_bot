## Grammatika
**Nuqta:** أَفْعَلَ — التَّعْدِيَة
IV bob vazni: أَفْعَلَ (o'zak boshiga hamza أَـ, 1-harf sukunli). Asosiy ma'no: SABABIYAT / o'timlilik («-dirmoq, qildirmoq»): دَخَلَ (kirdi) → أَدْخَلَ (kiritdi), خَرَجَ (chiqdi) → أَخْرَجَ (chiqardi). Mashhur misol: سَلِمَ (salomat bo'ldi) → أَسْلَمَ (Allohga taslim bo'ldi = musulmon bo'ldi). Masdari إِفْعَال: إِسْلَام (Islom), إِرْسَال (yuborish). Hozirgi zamoni: يُفْعِلُ (يُرْسِلُ).
- سَلِمَ ← أَسْلَمَ — omon bo'ldi → taslim bo'ldi (Islom)
- خَرَجَ ← أَخْرَجَ — chiqdi → chiqardi
- أَرْسَلَ — yubordi
- مَصْدَر: إِسْلَام · إِرْسَال — masdar: Islom, yuborish
