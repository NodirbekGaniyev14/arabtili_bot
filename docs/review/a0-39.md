## Grammatika
**Nuqta:** القِرَاءَة
Ravon o'qish uchun uchta narsani birlashtirasiz: (1) harfning boshi/o'rtasi/oxiri shakli, (2) qisqa unlilar (fatha/kasra/damma), (3) cho'ziq unlilar (madd). O'qishda ko'zingizni O'NGDAN CHAPGA harakatlantiring va bo'g'inlab (bo'lib) o'qing: كِ + تَا + بٌ.
- بَيْت — uy — bay-t
- كِتَاب — kitob — ki-taab
- مَدْرَسَة — maktab — mad-ra-sa
- قَلَم — qalam — qa-lam
- الشَّمْس — quyosh — ash-shams

## Mikro-test javoblari
1. [mcq] كِتَاب so'zi qanday o'qiladi? → **kitaab (cho'ziq aa)**
2. [mcq] الشَّمْس so'zi qanday o'qiladi? (quyosh harfi) → **ash-shams**
3. [translate_ar_uz] بَيْت → **uy**
4. [translate_uz_ar] qalam → **قَلَم**
5. [match_root] كِتَاب so'zining o'zagi qaysi? → **ك ت ب**
6. [harakat] 'madrasa' so'zini to'g'ri harakatlangan shaklini tanlang. → **مَدْرَسَة**
7. [order_words] So'zlarni to'g'ri o'qish tartibida (o'ngdan chapga) joylashtiring: bo'g'inlar. → **كِ تَا بٌ**
