## Grammatika
**Nuqta:** نِظَامُ الجَذْر وَالوَزْن
A1 xulosasi: har so'z = JADR (o'zak, 3 undosh) + VAZN (qolib). Asosiy vaznlar: فَعَلَ (fe'l), فَاعِل (bajaruvchi), مَفْعُول (ob'ekt), مَفْعَل/مَفْعَلَة (joy), فَعِيل (sifat), مُفَعِّل (kuchaytirilgan bajaruvchi), فِعَالَة (ish nomi/masdar). Bir o'zakni turli vaznlarga solib, bog'liq so'zlar oilasini yasaysiz. Yangi so'z ko'rsangiz: o'zakni toping → vaznni taning → ma'noni taxmin qiling.
- دَرَسَ — o'qidi (fe'l)
- مُدَرِّس / دَارِس — o'qituvchi / o'quvchi
- مَدْرَسَة — maktab (joy)
- دِرَاسَة — ta'lim (ish nomi)
