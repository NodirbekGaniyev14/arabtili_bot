## Grammatika
**Nuqta:** Fatha
Fatha — harf USTIGA qo'yiladigan kichik qiya chiziqcha. U harfga «a» tovushini qo'shadi. بَ = «ba», تَ = «ta», نَ = «na». Bu — arab tilidagi birinchi va eng ko'p uchraydigan unli.
- بَ — «ba»
- تَ — «ta»
- نَ — «na»
- مَ — «ma»
- لَ — «la»

## Mikro-test javoblari
1. [mcq] Fatha (َ) qaysi tovushni qo'shadi? → **«a»**
2. [mcq] «ba» bo'g'ini qaysi? → **بَ**
3. [mcq] Fatha harfning qayeriga qo'yiladi? → **ustiga**
4. [harakat] «na» bo'g'inini tanlang: → **نَ**
5. [mcq] «ma» qaysi bo'g'in? → **مَ**
6. [mcq] Qaysi bo'g'inda FATHA bor? → **تَ**
